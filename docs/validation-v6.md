验证日期：2026-09-08。测试使用隔离 Docker 项目 `aoteman-sqlite-integration`（8789）及独立 SQLite 卷；未把测试玩家写入线上库。

## 功能与持久化

- 74 项 Node 逻辑测试、43 项 Python 存档 API 测试通过。
- 双援护分别调度：迪迦先出手，赛罗随后加入；相同时间的攻击按迪迦、赛罗、怪兽顺序处理。赛罗尾刀、总伤害统计、三人合击与暂停均有单测。
- 三重必杀消耗 30 光能，固定 84 伤害（以剩余生命为上限），三人同步光线持续 1100ms；致胜攻击立即结算保存，动画结束后再转为胜利动作与结果弹层。
- 真实浏览器完成濒危、召唤两位伙伴、三人必杀及胜利。结果弹层尚未关闭时 SQLite 已有 40 经验、20 星光和 1 胜场，刷新不重复奖励。
- 成长回应测试覆盖真实训练、每日礼物、成长航线、战斗跨级；正常保存回执不打断动作，刷新不重播，下一次照顾动作能接管。
- 原有战斗操作、成长存档、免费防御训练三套浏览器回归通过；训练不修改服务器存档 revision。

## iPad 兼容性范围

使用 Playwright 1.62.1 的 Chromium 和 macOS WebKit 26.5，DPR 2、触控输入和 coarse pointer。验证视口：

| 场景 | CSS 视口 |
| --- | --- |
| iPad 竖屏 | 834 × 1194 |
| iPad 横屏 | 1194 × 834 |
| Safari 工具栏占用空间 | 834 × 1050、1194 × 750 |
| 分屏 | 600 × 834 |
| 手机回归 | 375 × 812、430 × 932 |

检查六个技能及暂停/退出均不小于 44×44px、直接可点、没有水平溢出；角色绘制不截断，三束光线与各自手腕及怪兽目标的误差小于 2 CSS px。检查旋转和视口高度变化保留原战斗状态；通过 visibilitychange 生命周期事件检查后台暂停与计时冻结。减少动态效果时保留静态动作和可读提示。

这属于 WebKit 与触控视口兼容性测试，**没有使用实体 iPad Pro M1，也不能代表该设备的实测帧率或所有 iPadOS Safari 版本**。后台生命周期测试使用浏览器事件模拟，不能等同于实体设备切应用。

## 部署与进度

按项目约定推送 Git 后，在服务器 `/data/aoteman` 使用 `./deploy.sh` 更新。运行中的 SQLite 继续使用服务器 `aoteman_data` 卷，更新前自动创建一致性快照；不从本地库或 Git 空模板覆盖成长进度。

上线后检查 Git SHA、Web/API 健康、公开静态资源，以及升级前后数据库逻辑内容的摘要与完整性。实际部署证据保留在本机忽略的 `test-results` 目录，不包含在公开仓库中。
