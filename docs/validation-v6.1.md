# v6.1 银河真人皮套形象验证

验证日期：2026-09-24。

## 素材与动作

主角使用圆谷官方角色页的 403×948 透明皮套照片，部署文件与下载原图逐字节一致。SHA-256：`9ff342f98f82506583528ceedefcbf812fbf3136eca1288ec0e16a3238fe03dd`。待机展示完整照片，动作通过 SVG 分层、关节变换及游戏光效实现。图片来源和权利归属见 [素材说明](../public/assets/ginga/README.md)。

人工检查待机、挥手、X 防御、光线、出拳、敬礼和升级动作。角色共享于基地、战斗和防御训练。受伤与回血文字使用独立头部锚点并计入文字高度，避免遮住真人头部；iPad 横屏三人战斗的预警移到主角和怪兽之间。

## 验证范围

- 74 项 Node 逻辑测试、43 项 Python 存档 API 测试通过。
- Chromium、WebKit 检查官方图片本地解码、真人头身比例、独立 SVG ID、六种动作渲染与防御/光线手臂切换；无浏览器异常及外部素材请求。
- 触控训练触发升级抬臂和后续敬礼，经验从 70 增至 90、110；刷新保留 110 经验且不重复奖励。
- iPad 834×1194、1194×834、1194×750 视口检查六个技能和暂停/退出按钮可见、可点击且至少 44×44px；三人光线从各自手腕汇聚怪兽，固定帧偏差小于 2 CSS px。
- 免费防御训练浏览器回归覆盖 X 动作、三种训练结果、暂停与后台/停顿冻结、重试、减少动态效果和焦点恢复；训练不改变服务器成长存档版本。

浏览器测试使用本机原生临时服务器及临时 SQLite，未创建、启动或更新本地 Docker 容器。三人战斗布局通过公开引擎命令和加速步进进入场景，再暂停测量画面，不等同于完整实战录像。WebKit 与触控视口模拟不代表实体 iPad Pro M1 帧率实测。
